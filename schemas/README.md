# NIST OSCAL 1.1.2 JSON schemas

Unmodified copies of the SSP and profile schemas from the
[OSCAL v1.1.2 release](https://github.com/usnistgov/OSCAL/releases/tag/v1.1.2), kept so the
tests run offline. CI downloads the same files and checks them against `SHA256SUMS`.
